Troubleshooting & Fehlerbehebung Troubleshooting & FAQ

  • ECONNREFUSED: Stellen Sie sicher, dass auf der Workstation das Server-Gateway aktiv läuft (z.B. via npx @hybridlabor-api/bdb-os-remote server --port 9080). ECONNREFUSED: Ensure that the server gateway daemon is actively running on the workstation (e.g. via npx @hybridlabor-api/bdb-os-remote server --port 9080).
  • Windows SSH Server: Führen Sie den Installer aus und bestätigen Sie die automatische UAC-Installation, um OpenSSH auf Port 22 freizuschalten. Windows SSH Server: Run the installer and accept the automated UAC prompt to install and configure OpenSSH on port 22.
  • Verbindungstest: Prüfen Sie die Verbindung jederzeit mit npx @hybridlabor-api/bdb-os-remote status --host <TAILSCALE_IP> --port <PORT>. Connection Test: Test connectivity at any time with npx @hybridlabor-api/bdb-os-remote status --host <TAILSCALE_IP> --port <PORT>.
